# HEIF/AVIF structural corpus

All four files were produced on 2026-10-16 by this repository's `BmffDocument.Save` and
`BmffWriter`, using the complete original recipe in `../HeifFixtures.cs`, method `Create`.
They contain no downloaded or third-party media. The fixture source and generated bytes use the
repository license. Codec configurations and coded-image payloads are placeholder bytes: these
are container-conformance fixtures, not decodable HEVC or AV1 streams.

| File | Producer argument | Structure and clauses |
| --- | --- | --- |
| `heic.bin` | `heic` | One hvc1 image, hvcC, ispe and nclx colr; ISO/IEC 23008-12 HEVC image items and image properties. |
| `avif.bin` | `avif` | Two av01 items with av1C and pixi, one alpha auxiliary image and auxl; AVIF v1.2.0 §§2.1, 2.2.1, 4.1, 9.1. |
| `grid.bin` | `grid` | 2×2 grid descriptor in idat, four ordered dimg tiles and a thmb image; ISO/IEC 23008-12 grid derivation and thumbnails; ISO/IEC 14496-12 §8.11.11 idat. |
| `metadata.bin` | `metadata` | hvc1 plus Exif and application/rdf+xml items with cdsc references; Exif has a nonzero TIFF-header offset; ISO/IEC 23008-12 Exif/XMP metadata. |

To regenerate, write the result of `HeifFixtures.Create(argument)` to each corresponding file.
`HeifCorpusTests` independently regenerates and compares every byte during ordinary tests.
The method emits once to measure mdat's start, assigns the fixed-width iloc offsets, then emits
the final file through BMFF. The initial metadata precedes mdat so edits exercise relocation.

Malformed derivatives are generated by `HeifMalformedFixtures` from these same writer recipes.
Its comments identify the changed fields. The overflow case first writes valid eight-byte offset
fields, then overwrites the base offset with UInt64.MaxValue. No malformed file is downloaded.
The linked Content.Binary `TruncationCorpus` checks every prefix of each HEIF box header, including
the large-size header; synthetic resource bombs and a sparse 40 GiB idat are authored in tests.

Specification references were reviewed on 2026-10-16. Tests use ISO/IEC 23008-12 clause titles for
image properties/derived images/metadata where numbering varies by edition, the BMFF package's
established ISO/IEC 14496-12 item-box numbering, and AVIF v1.2.0 numbered clauses. This corpus
does not certify codecs, image sequences, external references, construction method 2 or all MIAF
profile requirements.
