# Web area overview

Web.ControlPlane adds reusable resource-management middleware to the Web feature family. The twelve generic resource Hosting modules consume it privately to expose readiness, liveness, health, endpoints, stop, and command envelopes. Web applications receive its public pipeline extension through App.Web.
