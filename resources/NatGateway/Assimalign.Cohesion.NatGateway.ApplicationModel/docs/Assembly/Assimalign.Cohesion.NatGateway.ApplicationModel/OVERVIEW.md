# Public API

`NatGatewayResource` inherits `PlannedResource`; `NatGatewayResourceOptions` inherits `ResourceOptions`. `INatGatewayResourceDescriptor` exposes the typed resource and ordinary dependency edges. `AddNatGateway` extends `IApplicationBuilder`; `NatGatewayResourceControlPlane.Create` returns an isolated `IResourceControlPlane` with no command kinds.
