# Database test scheduling audit (#1285)

Audited on the wave-11 base after #1350: 173 Task.Run invocations. DedicatedTestTask replaces 172; the parser concurrency test retains its unbounded Task.WhenAll. Of the original sites, 159 belong to directly bounded methods and 53 contain actor loops (overlap). The broader conversion also covers transitive disposal deadlines and concurrent peers. Paths and lines below identify the original sites, before imports shifted line numbers.

The shared source owns LongRunning actors. Async drivers retain a private TaskScheduler across ordinary awaits, without installing a SynchronizationContext. A plain LongRunning async delegate would return its thread on the first incomplete await. Product async operations still use their own continuation policy. The helper preserves exception and cancellation identity. Linked Compile sources avoid test-project references. A separate factory-call audit finds no other async StartNew delegate outside this helper; the pre-existing factory drivers are synchronous LongRunning work.

All seven xunit.runner.json files (Database, Cache, Embedded, KeyValuePair, KeyValuePair.Client, Sql, Storage) contain no parallelism cap. Existing deadlines of 25 seconds or more are hang guards, not performance targets; they are retained. Busy actors, even when they stop by a bounded run duration, own dedicated drivers. Worker latency checks retain their existing median/share aggregates over at least twelve samples; this audit adds no per-sample time maximum.

The sustained journal workloads stop at exact append counters at operation boundaries: forty configured sizes plus already-started operations. Test journal streams count successful append growth, actual truncations and maximum length at mutation points. The observer cannot lose complete cycles. Its five-minute timeout is only a hang guard. SQL cascade and the five B-tree entry guards count physical entry-directory reads; no clock ratio decides them. The internal null observer adds no default counter or process-wide atomic.
