# Assimalign.Cohesion.Database.Graph.Protocol

Shared Graph wire contracts for the remote client and engine. The package owns 13 existing public types, their codecs and the single model protocol-family identity. Consumers import `Assimalign.Cohesion.Database.Graph.Protocol` and explicitly select an engine only for embedded or server work.
