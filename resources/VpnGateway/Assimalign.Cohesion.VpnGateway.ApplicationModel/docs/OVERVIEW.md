# VpnGateway ApplicationModel

Compose a build-produced manifest with `builder.AddVpnGateway(manifest, options)`. The typed descriptor supports dependency edges; the resource produces a platform-neutral Deployment plan. Generated resource code calls `VpnGatewayResourceControlPlane.Create()`. All command kinds remain deferred.
