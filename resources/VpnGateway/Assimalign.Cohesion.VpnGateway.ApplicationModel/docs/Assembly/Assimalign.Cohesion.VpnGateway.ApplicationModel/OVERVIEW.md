# Public API

`VpnGatewayResource` inherits `PlannedResource`; `VpnGatewayResourceOptions` inherits `ResourceOptions`. `IVpnGatewayResourceDescriptor` exposes the typed resource and ordinary dependency edges. `AddVpnGateway` extends `IApplicationBuilder`; `VpnGatewayResourceControlPlane.Create` returns an isolated `IResourceControlPlane` with no command kinds.
