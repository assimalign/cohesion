# Repository fixtures

These checks validate contracts shared across repository areas. They are not shipped packages.
Project-owned acceptance hosts and AOT guards stay with the projects they exercise.

| Fixture | Checks |
| --- | --- |
| `IntegrationCheck` | Generated component registration across Http, Web, and DependencyInjection. |
| `ResourceGenerationCheck` | Strongly typed error resources generated by the shared MSBuild targets. |
| `SdkSmoke` | Package-only App, Web, Database, and analyzer consumers copied to an isolated workspace by `scripts/sdks/Invoke-SdkConsumerSmoke.ps1`. |

Build `build/Tasks/Assimalign.Cohesion.Build.Tasks.csproj` first, then build
`fixtures/Assimalign.Cohesion.Fixtures.slnx`. Run ResourceGenerationCheck to verify its assertions:

```powershell
dotnet run --project fixtures/ResourceGenerationCheck/Assimalign.Cohesion.ResourceGenerationCheck.csproj
```

SdkSmoke stays outside solutions because its SDKs must resolve from a packed feed. Its
[README](SdkSmoke/README.md) describes the package validation commands.
